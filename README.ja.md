# dsh-local-font-picker

DeepSeek Harness（DSH）Web UI 用のコミュニティプラグインです。PC にインストールされているフォントを一覧から選択し、UI フォントとコードフォントを自由に変更できます。

> **ご注意**: 本プラグインはコミュニティによって管理されており、DeepSeek Harness 本体の公式配布物には含まれていません。

### 機能
- **ローカルフォントの列挙**: `window.queryLocalFonts()`（Local Font Access API）を使用して、PC にインストールされているフォントを一覧表示します。
- **シームレスな設定連携**: 選択したフォントは DSH 本体のフォント設定（`ctx.theme.setFontFamily`）に直接書き込まれます。適用・保存・復元はすべて本体側で管理されるため、設定の不整合が起こりません。
- **フォント名の直接入力**: Local Font Access API 非対応のブラウザでも、フォント名を直接入力することで変更が可能です。
- **低負荷設計**: プラグイン側では独自に設定を保持せず、DSH 本体の設定と常に同期します。
- **本体改変不要**: DSH 本体のソースコードを書き換える必要はなく、プラグインの導入のみで動作します。

**重要な注意点**:
DSH **0.2.1-alpha.2** で本体にフォント指定機能が追加されました。0.3.0 以降はこの本体設定そのものを書き込むため、プラグイン側には競合する状態が残りません。
一方、それ以前のプラグインリリース（0.1.x–0.2.x）は独自の写しを並行して保持しており、本体設定との併用は検証されていません。v0.2 以前から 0.3.0 への更新を行った場合、古い設定は自動的に引き継がれません。一度設定行でフォントを選択し直してください。

### 導入方法
1. リポジトリをローカルにチェックアウトします。
2. 対象の DSH プロファイルに追加します。
   ```sh
   dsh plugin --profile web add <このリポジトリへの絶対パス>
   ```
3. DSH Web を再起動してください。

### 使い方
**Settings $\rightarrow$ General $\rightarrow$ フォント** を開いて設定します。

- **PCフォントを読み込む**: ブラウザにローカルフォント一覧へのアクセス許可を求めます。
- **UIフォント / コードフォント**: 一覧から選択するか、フォント名を直接入力してください。
- **既定に戻す**: UI フォントおよびコードフォントを本体の既定値にリセットします。

※ 表示言語はブラウザの優先言語設定に基づきます（`ja` または `ja-*` で日本語、それ以外は英語）。言語設定を変更した場合は、ページの再読み込みが必要です。

### プライバシーと権限
- **フォントアクセス**: 「PCフォントを読み込む」を実行すると、Local Font Access API を介してフォントのメタデータを参照します。
- **限定的な動作**: フォントファイルの複製、アップロード、および外部ネットワーク通信は一切行いません。
- **データ保存**: 設定値は DSH 本体の設定にのみ保存され、プラグイン側で独自にデータを保持することはありません。

### 制約
- **ブラウザ対応**: Local Font Access API は主に Chromium 系デスクトップブラウザで動作します。
- **本体バージョン**: 本体への状態管理委譲機能が必要なため、DSH **0.2.1-alpha.2** 以降が必要です。
- **言語反映**: 言語判定はモジュール読み込み時に一度だけ行われるため、変更後は再読み込みが必要です。
