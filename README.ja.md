# dsh-local-font-picker

[English](README.md) | 日本語

DeepSeek Harness（DSH）Web UI 用のコミュニティプラグインです。PCにインストール済みのフォントを選び、UIフォントとコードフォントを変更します。

> DeepSeek Harness 本体に同梱される公式プラグインではなく、コミュニティ管理の外部プラグインです。

## 機能

- `window.queryLocalFonts()`（Local Font Access API）でローカルフォントを列挙
- DSH の Theme API / Slot API で UI フォントとコードフォントを個別変更
- 選択したフォント名だけをブラウザの `localStorage` に保存
- Local Font Access API 非対応ブラウザではフォント名の直接入力に対応
- DSH 本体の改変なし、プラグイン側のビルド不要

Host 側の `index.js` は意図的に no-op で、機能は Web クライアント側だけで動作します。

## 導入

このリポジトリのローカル checkout を対象 DSH profile に追加します。

```sh
dsh plugin --profile web add <このリポジトリへの絶対パス>
```

追加後に DSH Web を再起動します。

## 使い方

**Settings → General → フォント** を開きます。

- **PCフォントを読み込む**: ブラウザにローカルフォント一覧へのアクセスを要求
- **UIフォント / コードフォント**: 一覧から選択、またはフォント名を直接入力
- **既定に戻す**: Theme 上書きと保存設定を解除

表示言語はブラウザの優先言語から決まり、DSH 本体の Language 設定変更には追随しません。

## プライバシーと権限

**PCフォントを読み込む** を実行すると Local Font Access API を呼び出し、ブラウザが許可確認を表示する場合があります。許可後は、このページからインストール済みフォントのメタデータを参照できます。

このプラグインは次の動作を行いません。

- フォントファイルの読み込み・複製
- フォント情報のアップロード
- ネットワーク通信

保存するのは選択したフォントファミリー名だけで、ブラウザ origin ごとの `localStorage` に保持します。

表示言語はブラウザの優先言語から決まり、DSH 本体の Language 設定変更には追随しません。

## 制約

- Local Font Access API は主に Chromium 系デスクトップブラウザ向けです。非対応ブラウザでも直接入力は利用できます。
- 設定はブラウザ origin ごとに管理されます。
- 表示言語はモジュール読み込み時に一度だけ決まります。ブラウザの優先言語を変えた後はページを再度読み込むまで反映しません。
- DSH は開発中のため、プレリリース間でクライアント拡張契約が変わる可能性があります。
