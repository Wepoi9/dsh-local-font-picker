# dsh-local-font-picker

[English](README.md) | 日本語

DeepSeek Harness（DSH）Web UI 用のコミュニティプラグインです。PC にインストールされているフォントを選び、UI フォントとコードフォントを変更できます。

> DeepSeek Harness 本体に同梱される公式プラグインではなく、コミュニティ管理の外部プラグインです。

## 機能

- `window.queryLocalFonts()`（Local Font Access API）でローカルフォントを列挙
- 選択したフォントを DSH 本体のフォント設定（`ctx.theme.setFontFamily`）に書き込み、適用・保存・復元は本体側で管理
- プラグイン側では設定を保持しない（`localStorage` や Theme トークンの上書きを使用せず、本体設定と常に同じ値を共有）
- Local Font Access API 非対応ブラウザではフォント名の直接入力に対応
- DSH 本体の改変なし、プラグイン側のビルド不要

Host 側の `index.js` は意図的に何も処理せず、機能は Web クライアント側だけで動作します。

DSH **0.2.1-alpha.2** で本体にフォント指定機能が追加された。0.3.0 以降はこの本体設定そのものを書き込むため、プラグイン側には競合する状態が残らない。それ以前のプラグインリリース（0.1.x–0.2.x）は独自の写しを並行して保持し、本体設定との併用は一度も検証していない。v0.2 以前から 0.3.0 への更新で古い設定は自動移行されない。プラグインは古い `localStorage` の写しを読み込まず、Theme トークンも上書きしなくなるため、設定行で一度フォントを選ぶまで本体フォント設定の値（クリーンな更新では既定値）がそのまま表示される。古いバージョンがブラウザに残した設定項目は以降参照されず、残しても動作に影響しません。削除しても他の動作には影響しません。その他の後続バージョンについても、確認が取れるまでは互換性を前提としません。

## 導入

このリポジトリをローカルにチェックアウトし、対象の DSH プロファイルに追加する。

```sh
dsh plugin --profile web add <このリポジトリへの絶対パス>
```

追加後に DSH Web を再起動する。

## 使い方

**Settings → General → フォント** を開く。

- **PCフォントを読み込む**: ブラウザにローカルフォント一覧へのアクセスを要求
- **UIフォント / コードフォント**: 一覧から選択、またはフォント名を直接入力。値は DSH 本体のフォント設定に書き込まれ、本体側のフォント行と常に同じ値を共有する
- **既定に戻す**: UIフォントとコードフォントを、それぞれ本体の既定フォントリストに戻す

表示言語はブラウザの優先言語から決まり、DSH 本体の Language 設定変更には追随しない。

## プライバシーと権限

**PCフォントを読み込む** を実行すると Local Font Access API を呼び出し、ブラウザにアクセス許可の確認が表示される場合があります。許可後は、このページからインストール済みフォントのメタデータを参照できます。

このプラグインは次の動作を行わない。

- フォントファイルの読み込み・複製
- フォント情報のアップロード
- ネットワーク通信

フォントファミリー名は DSH 本体の設定に保存されます。プラグイン側では `localStorage` を含め、独自の設定を保持しません。


## 制約

- Local Font Access API は主に Chromium 系デスクトップブラウザ向けで、非対応ブラウザでも直接入力は利用できる。
- フォント設定は DSH 本体の設定が保持し、本体側のフォント行と共有する。プラグイン独自の保存先は無い。
- 本体への状態管理の委譲には DSH **0.2.1-alpha.2** 以降が必要（本体のフォント指定機能がこの版で追加されたため）。
- 表示言語はモジュール読み込み時に一度だけ決まる。ブラウザの優先言語を変えた後はページを再度読み込むまで反映されない。
- DSH は開発中のため、プレリリース間でクライアント拡張契約が変わる可能性がある。
